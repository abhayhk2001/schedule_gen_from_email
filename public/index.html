Email Event Extractor

Turn emails into calendar events — paste, extract, create.

Try it API Outlook add-in

What it does

Reads the contents of an email with an LLM and returns every distinct calendar event as structured JSON (date, time, timezone, end_date, end_time, whole_day, event_name, description). The companion Outlook add-in reads the email you're viewing, calls the same API, and pushes the events straight into your calendar using Microsoft Graph SSO.

Two providers, selectable per request (OPENAI_API_KEY / MINIMAX_API_KEY):

  • gpt-4o-mini · OpenAI
  • MiniMax-M3 · MiniMax (OpenAI-compatible)

Try it

Paste the body of any email below. Pick a model and click Extract events. Everything runs against this deployment's /api/extract-event endpoint.

Events

API

POST /api/extract-event

curl -X POST https://<your-deployment>.vercel.app/api/extract-event \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "email": "Reminder: Career Fair on Friday Oct 3, 2025 from 1:00 PM to 5:00 PM at the Illini Union."
  }'

Response shape, event fields, multi-day rules and error codes are documented in the README.

Outlook add-in

Sideload the manifest into Outlook to extract events from the email you're viewing and create them in your calendar with a single click. Uses Microsoft Graph SSO via Office.auth.getAccessToken.

  1. Download the manifest: manifest.xml.
  2. In Outlook on the web: Settings → Manage integrated add-ins → Add a custom add-in → Add from file…. Pick the manifest you downloaded.
  3. Open any message, click the Extract Events button on the ribbon.

The manifest's <WebApplicationInfo> block needs a real Azure App Registration GUID before sideloading — see the README's "Outlook add-in" section.
